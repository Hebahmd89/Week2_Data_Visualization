# Week 2 Data Visualization Laboratory

This repository contains my Week 2 Data Visualization laboratory using the Palmer Penguins dataset.

The lab explores the relationship between flipper length and body mass across penguin species using Matplotlib, Seaborn, and Altair.

## Contents
- `notebooks/` – Jupyter Notebook for the laboratory
- `figures/` – Saved visualization outputs
- `AI_USE.md` – AI use statement

## Dataset
Palmer Penguins dataset by Allison Horst.
